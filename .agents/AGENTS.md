# AGENTS.md

## Project Overview
kotoflip is a flashcard-based vocabulary learning app that lets users flip between original words and translations across multiple languages.

## Tech Stack
- Flutter / Dart
- State management: BLoC (https://bloclibrary.dev/)
- Lint: flutter_lints (see analysis_options.yaml)

## Preconditions

Before implementing any functional spec listed in `.agents/docs/SPECS.md`, consult the `plan-writer` skill (see `.agents/skills/plan-writer/SKILL.md`) to create/update plan.md, decision.md, and progress_N.md.
