# 儲存與驗證邏輯整合

> 對應 [plan.md](plan.md) 「待執行」項目：儲存與驗證邏輯整合（必填/長度檢查、label 預設規則、完成後導回 Home）

執行前需參閱 `decision.md` 檔案才可開始執行。

## 表單驗證邏輯

- [ ] 原文：必填，100 字元內
- [ ] 譯文：必填，100 字元內
- [ ] label：必填，20 字元內
- [ ] 總 label 數已達 10 組時，禁止新建全新 label（僅能從既有 label 中選取）

## 存檔流程

- [ ] 點擊「完成」→ 驗證通過後寫入 sqlite（`word_cards` + 對應 `label_id`）
- [ ] label 為新輸入值時，先寫入 `labels` 表再取得 `label_id`
- [ ] 存檔成功後卡片轉為 read mode（顯示編輯 icon，但編輯行為不在本次範圍）

## 完成後導頁

- [ ] 釐清「完成」按鈕的行為範圍：是否每次點擊「完成」都會導回 Home，或僅在使用者不再點擊「新增」繼續下一張時才導回 Home（目前 decision.md 兩則決策看似分別描述「單張存檔」與「離開頁面」，實作前需與開發人員再次確認觸發時機是否為同一顆按鈕）
- [ ] 依確認結果實作導頁邏輯（Navigator 導回 Home）

## 總結

尚未開始執行，待審閱本檔案任務拆分後依序進行。其中「完成後導頁」章節有一項待釐清的行為細節，需要在開始實作前先確認。
